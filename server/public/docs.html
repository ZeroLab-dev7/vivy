Quick Start Guide

Get Vivy up and running in your Discord server in under 5 minutes.

5 min read Updated July 2026

Overview

Vivy is an all-in-one Discord bot offering moderation, leveling, economy, giveaways, voice rooms, auto-moderation, verification, applications, and more — all configurable through a web dashboard.

No coding required! Everything is managed through the dashboard. The default command prefix is ?.

Step 1: Invite Vivy

1
Visit the website
Go to the Vivy website and click Add to Discord.
2
Select your server
Choose the server from the dropdown. You must have Manage Server permission.
3
Authorize permissions
Review and approve the requested permissions, then click Authorize.
4
Login to Dashboard
Open the dashboard at /auth/discord/login, select your server, and start configuring.

Support

Frequently Asked Questions

Answers to the most common questions regarding Vivy Discord integrations.

5 min read
How do I invite Vivy to my guild?
Visit the main page, click Add to Discord, choose your guild and authorize the permissions. Ensure you hold Manage Server rights.
What is the default command prefix?
The default prefix is ?. You can change this or add extra prefixes by running ?addprefix [prefix] or visiting Security & Prefix in the web dashboard.
Why doesn't my guild show in dashboard?
You must have Manage Server permissions on the target server and the bot must be invited. Log out and back in to refresh OAuth lists.
Bot does not respond to commands.
Verify: (1) Vivy is online in member list, (2) you are using correct prefix (default: ?), (3) the bot has Send Messages and View Channel permissions. You can also mention @Vivy help.
Why can't the bot warn or mute a member?
Discord role hierarchies apply. Vivy's highest role must be placed higher than any member's role it tries to moderate. Vivy cannot moderate the server owner.
Dashboard says the bot is offline.
The bot may be undergoing minor updates or service restarts. If offline longer than 15 minutes, check the support channels.
Is my server data secure?
Yes. We only store settings, coins balances, warnings, and XP records needed to operate the bot. Client-dashboard authentication is secured via Discord OAuth.

Troubleshooting

Quick fixes for common bot and dashboard configuration errors.

6 min read

Bot offline or silent

1
Check status indicator
Confirm bot is online in server member list.
2
Try direct mentions
Invoke @Vivy help. If it replies, the prefix has been customized. Check prefix configurations.
3
Examine Channel Permissions Override
Confirm Vivy has permissions: View Channel, Send Messages, and Read Message History.

Dashboard login errors

  • Try logging out and back in to clear OAuth sessions.
  • Enable browser cookie support (disabled cookies block OAuth handshakes).
  • Disable private browsing or VPN filters if they block authorization tokens.

Response Errors

Status CodePotential CauseResolution
403 ForbiddenRole hierarchy blocks commandMove Vivy role higher in settings
401 UnauthorizedSession token expiredRefresh dashboard login session
429 Rate LimitAPI limit exceededWait for resets
